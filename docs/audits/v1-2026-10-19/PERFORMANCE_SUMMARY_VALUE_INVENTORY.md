## V1-096 — daily-user grain explanation is missing from Performance Summary

**P2; confirmed label/provenance gap.** `shared/ga4-traffic-window.ts:14–30` intentionally adds daily Users. Exact helper/card execution with daily counts1 and1 returns2. The Performance card at1471–1479 says Total Users and Sources: Google Analytics, with no grain explanation. GA4 Overview at `ga4-metrics.tsx:6865` explicitly explains that the same user may appear on multiple days; `GA4/OVERVIEW.md:171–176` describes the same intended daily-sum architecture. The calculation agrees with intended design; this finding does not propose changing it.

Google's standard Total users definition counts unique users in the specified date range. A sum of daily unique counts can exceed that period-distinct number when someone returns on another day. [Official GA4 user metrics](https://support.google.com/analytics/answer/12253918?hl=en) (verified2026-10-20 local date). The two aggregate fixture rows cannot reveal whether their users overlap; no specific deduplicated value is inferred from them.

Release impact: executives can reasonably compare the card against a different GA4 grain. Preserve the defined calculation and surface its grain/window consistently in Performance Summary and each included artifact. Remaining PDF/Executive/other user-label consumers need independent checks rather than assuming the Overview tooltip propagates automatically.
