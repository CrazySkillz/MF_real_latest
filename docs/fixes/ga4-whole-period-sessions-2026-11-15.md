# GA4 whole-period Sessions correction

Scope: test-app release only. No production refresh, database write, deployment or GA4 event submission is authorized by this task.

Root cause: Overview summarized persisted daily Sessions. GA4 Sessions is a unique-count metric; daily or campaign counts cannot reconstruct its whole-period total. The existing exact-window Users request now also obtains Sessions, engagedSessions and engagementRate without grouping dimensions, using the same property, dates and campaign attribution scope. No extra aggregate requests are introduced.

Daily chart facts and financial/conversion inputs stay unchanged. Aggregate metadata is published atomically with the existing Overview snapshot. Daily reconciliation remains against the separately retained daily Sessions count. Summary, Campaign Breakdown/Comparison, derived conversion and engagement rates, KPI/Benchmark inputs, alert inputs, campaign totals, snapshots and affected PDF builders consume the exact-window totals. Existing legacy snapshots retain their existing format until the next successful refresh. A present but invalid new aggregate fails closed.

Real evidence: Mock property 542352127, 2026-09-04–2026-11-15, exact selected campaigns yesop_brand_search and yesop_retargeting. Read-only GA4 requests on 15 November returned 4,472 aggregate Sessions versus 4,497 summed daily Sessions. A separate Sessions-only query returned the same 4,472. Earlier source evidence returned 4,329 versus 4,375; source processing advanced between captures. The current captures retain 440 conversions, EUR114,314.60 native revenue, 3,246 engaged Sessions and provider engagementRate 0.7258497316636852. Campaign counts are 3,159 and 1,358; their sum is not used as the combined total.

The committed fixture contains actual Mock-property responses and no credentials. Regression tests replay the provider requests, reject missing/negative/sampled/thresholded/truncated responses, verify exact property/date/campaign boundaries, preserve daily facts and financial inputs, and generate actual Overview, Custom and Campaign Comparison PDFs using those captured values. Current automated local results are recorded in audit-temp/period-sessions-release. Required GitHub checks, hosted test deployment and hosted verification must pass before release completion is claimed. Live remains unchanged.
